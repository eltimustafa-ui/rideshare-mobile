# RideShare (Java 3)

Ushtrim i javës 3, lënda Mobile 2026/2027: tre ekrane për një aplikacion udhëtimesh,
nga skiza te kodi. Aplikacioni është në `aplikacioni/`, raporti në `java-03.md`.

## Si ekzekutohet

```bash
cd aplikacioni
npm install
npm run dev
```

Hape http://localhost:3000. Faqet: `/` (lista), `/udhetimi/1` (detajet),
`/udhetimi/1/kerkesa` (kërkesa e simuluar), `/udhetimi/99` (nuk gjendet).
